# Privacy Policy - Twitter Podcast Queue

**Last updated: December 25, 2024**

## Overview

Twitter Podcast Queue is committed to protecting your privacy. This extension operates entirely on your local device and does not collect, transmit, or store any personal data on external servers.

## Data Collection

**We do NOT collect:**
- Personal information
- Browsing history
- Tweet content (beyond what you explicitly save)
- User credentials
- Analytics or usage data
- Any data that could identify you

**We DO store locally:**
- Tweet URLs you choose to save
- Tweet classification (single/thread/conversation)
- Timestamps of when you saved tweets
- This data is stored only in your browser's local storage

## Data Usage

The extension only uses data for:
- Displaying your saved tweet queue
- Exporting your queue as JSON when requested
- Providing the core functionality of the extension

## Data Storage

- All data is stored locally using Chrome's storage API
- Data never leaves your device unless you explicitly export it
- No cloud storage or external databases are used
- Data is automatically deleted if you uninstall the extension

## Third-Party Access

- No third parties have access to your data
- No data is shared with Twitter/X or any other service
- No external APIs are called with your data
- The extension only interacts with Twitter/X's public interface

## Permissions

The extension requests these permissions:
- **Storage**: To save your tweet queue locally
- **Downloads**: To export your queue as JSON files
- **Tabs**: To open tweet links in new tabs
- **Host permissions for twitter.com and x.com**: To inject the save buttons

## Data Security

- Data is stored using Chrome's secure storage APIs
- No network transmission of personal data
- No external dependencies that could compromise security

## Your Rights

You can:
- View all your saved data through the extension popup
- Export your data as JSON at any time
- Clear all your data using the "Clear All" button
- Uninstall the extension to remove all data

## Changes to Privacy Policy

We will update this privacy policy if our practices change. Check this page periodically for updates.

## Contact

If you have questions about this privacy policy, please contact us through our GitHub repository.
